# Развертывание приложений

## Подготовка

- [ ] Определены версия приложения и источник артефакта.
- [ ] Проверены тесты и совместимость зависимостей.
- [ ] Конфигурация отделена от кода.
- [ ] Секреты передаются безопасным способом.
- [ ] Проверены миграции и обратная совместимость.
- [ ] Определены health/readiness endpoints.
- [ ] Подготовлен план отката.

## Развертывание

- [ ] Зафиксирована текущая версия.
- [ ] Проверена резервная копия данных, если изменение затрагивает данные.
- [ ] Развернута новая версия.
- [ ] Выполнены миграции по утверждённой процедуре.
- [ ] Проверены логи запуска.
- [ ] Проверены health checks.
- [ ] Выполнен smoke test ключевых сценариев.
- [ ] Проверены метрики ошибок и производительности.
- [ ] Зафиксированы результат и время изменения.

## Откат

- [ ] Определены условия запуска rollback.
- [ ] Известно, можно ли откатить схему БД.
- [ ] Предусмотрен способ вернуть предыдущий артефакт и конфигурацию.
- [ ] После отката проверены доступность и целостность данных.

# Создание сервера

## 1. Планирование

- [ ] Определено назначение и класс критичности сервера.
- [ ] Определены владельцы: технический и бизнес-владелец.
- [ ] Определены окружение и размещение: production / staging / development.
- [ ] Оценены CPU, RAM, диск, IOPS, сеть и ожидаемый рост.
- [ ] Определены RPO и RTO для критичных данных и сервисов.
- [ ] Определены сетевые зоны, входящие и исходящие соединения.
- [ ] Составлена схема зависимостей.
- [ ] Определены требования к резервному копированию и мониторингу.

## 2. Базовая настройка ОС

- [ ] Установлена поддерживаемая версия Ubuntu Server LTS или Debian.
- [ ] Зафиксированы версия ОС, ядра и дата установки.
- [ ] Настроен уникальный hostname.
- [ ] Проверены дата, часовой пояс и синхронизация времени.
- [ ] Проверены разделы, файловые системы, точки монтирования и inode.
- [ ] Проверены SMART/состояние диска, если доступно.
- [ ] Установлены обновления безопасности.
- [ ] Установлены только необходимые системные пакеты.
- [ ] Настроены автоматические security updates согласно политике.
- [ ] Проверены systemd failed units.
- [ ] Настроена отправка системных уведомлений, если требуется.

## 3. Администрирование

- [ ] Создан персональный административный пользователь.
- [ ] Проверены sudo-права.
- [ ] Настроен SSH-доступ по ключам.
- [ ] Проверен вход в новой SSH-сессии до отключения старого способа доступа.
- [ ] Запрещён прямой root login по SSH.
- [ ] Парольная SSH-аутентификация отключена, если все необходимые пользователи используют ключи и предусмотрен аварийный доступ.
- [ ] Удалены/отозваны неактуальные учётные записи и ключи.
- [ ] Определён процесс выдачи и отзыва доступа.

## 4. Сеть и безопасность

- [ ] Настроены адресация, DNS и маршрутизация.
- [ ] Настроен firewall с политикой deny-by-default для входящих соединений, если это совместимо с архитектурой.
- [ ] Разрешены только необходимые входящие порты.
- [ ] Проверен доступ к серверу из доверенной сети и извне.
- [ ] Настроена защита SSH (например, Fail2ban или эквивалент).
- [ ] Проверены слушающие порты и активные службы.
- [ ] Настроен reverse proxy, если нужен.
- [ ] Настроен TLS и автоматическое продление сертификатов, если применимо.

## 5. Эксплуатационная готовность

- [ ] Настроен мониторинг ресурсов и доступности.
- [ ] Настроен сбор и ротация логов.
- [ ] Настроено резервное копирование конфигураций и данных.
- [ ] Выполнен тест восстановления.
- [ ] Подготовлен паспорт сервера.
- [ ] Зафиксированы открытые порты, сервисы, пользователи и точки хранения данных.
- [ ] Подготовлена инструкция аварийного доступа.
- [ ] Проведена финальная проверка по [[03 - Безопасность]] и [[09 - Мониторинг и логирование]].

## Критерий завершения

Сервер готов к передаче в эксплуатацию, когда все обязательные пункты выполнены или имеют документированное исключение, а доступ, резервирование и мониторинг проверены.

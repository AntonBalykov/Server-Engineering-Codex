# Сеть и доступ

## Инвентаризация

- [ ] Зафиксированы IP-адреса, интерфейсы, VLAN/подсети и маршруты.
- [ ] Зафиксированы DNS-записи и владелец домена.
- [ ] Составлен реестр портов: порт, протокол, сервис, назначение, источник доступа.
- [ ] Определены входящие и исходящие сетевые зависимости.

## Reverse proxy и TLS

- [ ] Внешний трафик проходит через согласованную точку входа.
- [ ] Внутренние сервисы не опубликованы напрямую без необходимости.
- [ ] TLS-сертификаты действительны и соответствуют доменам.
- [ ] Автоматическое продление проверено.
- [ ] Настроены безопасные параметры TLS согласно актуальным требованиям.
- [ ] Проверены заголовки и лимиты reverse proxy.
- [ ] Есть мониторинг срока действия сертификатов.

## Диагностика

- [ ] Проверяется DNS resolution.
- [ ] Проверяется маршрут до зависимостей.
- [ ] Проверяется доступность порта с разрешённой стороны.
- [ ] Проверяются логи proxy и ошибки upstream.
- [ ] Проверяется время ответа и TLS handshake.

## Изменения сети

- [ ] Изменения firewall согласованы с владельцами сервисов.
- [ ] До изменения удалённого firewall обеспечен альтернативный доступ.
- [ ] После изменения проверены все критичные входящие и исходящие соединения.

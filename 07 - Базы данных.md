# Базы данных

## Доступ и безопасность

- [ ] БД не доступна из публичной сети без строгой необходимости.
- [ ] Приложение использует отдельную роль с минимальными правами.
- [ ] Административные и прикладные учётные записи разделены.
- [ ] Секреты подключения хранятся безопасно.
- [ ] Включено шифрование соединений там, где этого требует модель угроз.
- [ ] Проверены сетевые ACL и firewall.

## Надёжность и производительность

- [ ] Определены требования к доступности.
- [ ] Контролируются соединения, блокировки и длительные запросы.
- [ ] Контролируются размер БД, рост таблиц и свободное место.
- [ ] Настроены журналы и метрики.
- [ ] Настроены maintenance tasks согласно типу БД.
- [ ] Миграции проверяются на staging или копии данных, если риск существенный.

## Backup и восстановление

- [ ] Выбран подходящий тип backup: logical, physical, snapshot, PITR — по требованиям.
- [ ] Зафиксированы расписание и retention.
- [ ] Ключи шифрования доступны уполномоченным лицам.
- [ ] Проверено восстановление на отдельной среде.
- [ ] Зафиксированы версия СУБД и порядок восстановления.

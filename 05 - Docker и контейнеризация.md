# Docker и контейнеризация

## Установка и конфигурация

- [ ] Docker Engine установлен из доверенного источника.
- [ ] Docker Compose Plugin установлен и версия зафиксирована.
- [ ] Определено место хранения Docker data-root.
- [ ] Настроена ротация Docker-логов.
- [ ] Оценены права доступа к Docker socket.
- [ ] Доступ к Docker daemon ограничен.

## Образы и контейнеры

- [ ] Используются закреплённые версии образов; для критичных production-компонентов рассмотрены digest.
- [ ] Контейнеры запускаются не от root, если приложение это поддерживает.
- [ ] Убраны лишние Linux capabilities.
- [ ] Файловая система read-only там, где возможно.
- [ ] Настроены healthcheck и restart policy.
- [ ] Заданы разумные CPU/RAM limits или reservations с учётом среды.
- [ ] Секреты не встроены в image layers.
- [ ] Образы регулярно пересобираются с обновлёнными базовыми слоями.
- [ ] Проверяются уязвимости образов.

## Compose-проекты

- [ ] Каждый проект имеет понятное имя и отдельную директорию.
- [ ] Порты опубликованы только при необходимости.
- [ ] Внутренние сервисы используют внутренние сети.
- [ ] Данные хранятся в volumes или контролируемых bind mounts.
- [ ] Описаны зависимости и порядок готовности сервисов.
- [ ] Конфигурация хранится в Git без секретов.
- [ ] Для каждого volume известны владелец и назначение.

## Очистка Docker

- [ ] Перед удалением выполнена инвентаризация контейнеров, образов, сетей, volumes и build cache.
- [ ] Установлена принадлежность каждого ресурса.
- [ ] Проверены активные и остановленные контейнеры.
- [ ] Проверено, не используется ли образ другими проектами.
- [ ] Проверены labels и Compose project.
- [ ] Volumes с данными не удаляются без отдельного подтверждения и backup.
- [ ] Не используется глобальная очистка (`prune -a`, удаление volumes) без оценки воздействия.
- [ ] После очистки проверены соседние проекты.

> [!danger] Запрет по умолчанию
> Не применять `docker system prune --volumes` на общем сервере как рутинную уборку. Сначала установить владельца и назначение каждого ресурса.

# Мониторинг и логирование

## Системные ресурсы

- [ ] CPU и load average.
- [ ] RAM и swap.
- [ ] Диск: заполнение, inode, latency/IOPS при необходимости.
- [ ] Состояние файловых систем и mount points.
- [ ] Сеть: ошибки интерфейсов, пропускная способность.
- [ ] Температура/SMART, если доступны.

## Сервисы и приложения

- [ ] Доступность критичных сервисов.
- [ ] Состояние контейнеров и healthchecks.
- [ ] Ошибки приложения и reverse proxy.
- [ ] Состояние БД и очередей.
- [ ] Срок действия TLS-сертификатов.
- [ ] Возраст последнего успешного backup.

## Логи и оповещения

- [ ] Определены источники логов и сроки хранения.
- [ ] Настроена ротация.
- [ ] Исключены секреты и чувствительные данные из логов.
- [ ] Настроены уведомления с понятным уровнем критичности.
- [ ] Проверен канал доставки уведомлений.
- [ ] Уведомления имеют владельца и инструкцию реакции.
- [ ] Проверено время на узлах для корректной корреляции событий.

## Качество мониторинга

- [ ] Есть тестовое событие для проверки alert pipeline.
- [ ] Нет постоянных неразбираемых ложных срабатываний.
- [ ] Для критичных alert определены runbook и ответственный.

# Управление изменениями

## Перед изменением

- [ ] Описана цель и причина.
- [ ] Указаны затрагиваемые серверы, проекты и сервисы.
- [ ] Установлены зависимости и владельцы.
- [ ] Оценены риски и возможный простой.
- [ ] Определено окно работ, если нужно.
- [ ] Есть backup или другой механизм восстановления.
- [ ] Есть план отката.
- [ ] Определены проверки после изменения.

## Во время изменения

- [ ] Выполняются только запланированные действия.
- [ ] Фиксируются команды и существенные результаты.
- [ ] При неожиданном эффекте работы остановлены для оценки.
- [ ] Не удаляются неизвестные ресурсы.

## После изменения

- [ ] Проверены сервисы и ключевые сценарии.
- [ ] Проверены логи, метрики и уведомления.
- [ ] Проверены зависимости и соседние проекты.
- [ ] Зафиксирован итог: успешно / откат / частичный успех.
- [ ] Обновлена документация и инвентаризация.

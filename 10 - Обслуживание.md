# Регламент обслуживания

## Ежедневно / автоматизированно

- [ ] Доступность критичных сервисов.
- [ ] Ошибки и аварийные события.
- [ ] Результат резервного копирования.
- [ ] Свободное место и inode.
- [ ] Состояние критичных контейнеров и процессов.
- [ ] Доставка критичных уведомлений.

## Еженедельно

- [ ] Анализ системных и прикладных логов.
- [ ] Проверка SSH-аутентификаций.
- [ ] Проверка Fail2ban или эквивалента.
- [ ] Проверка состояния firewall и слушающих портов.
- [ ] Проверка Docker-контейнеров, restart count и health.
- [ ] Проверка роста логов, volumes и build cache.
- [ ] Проверка возраста последнего успешного backup.

## Ежемесячно

- [ ] Плановое обновление ОС и пакетов.
- [ ] Проверка необходимости перезагрузки.
- [ ] Проверка обновлений приложений и образов.
- [ ] Анализ CPU, RAM, диска и сетевой нагрузки.
- [ ] Ревизия пользователей, ключей и прав.
- [ ] Ревизия открытых портов и внешних доступов.
- [ ] Проверка сертификатов.
- [ ] Проверка ёмкости и retention backup.

## Ежеквартально

- [ ] Тестовое восстановление критичных данных.
- [ ] Проверка RPO/RTO на практике.
- [ ] Аудит привилегированных доступов.
- [ ] Проверка плана аварийного восстановления.
- [ ] Ревизия установленных сервисов и владельцев.
- [ ] Проверка актуальности документации.

## После каждого изменения

- [ ] Проверена работоспособность затронутых сервисов.
- [ ] Проверены логи и метрики.
- [ ] Проверены соседние проекты, если инфраструктура общая.
- [ ] Обновлена документация.
- [ ] Заполнен [[Шаблоны/Отчет об обслуживании]] или [[Шаблоны/План изменений]].

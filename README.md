# Server Engineering Codex

Практическая база знаний по созданию, защите, эксплуатации и выводу из эксплуатации серверов.

> [!abstract] Главный принцип
> Сервер должен быть безопасным, предсказуемым, документированным, наблюдаемым и восстанавливаемым.

## Как пользоваться

1. При создании сервера пройди [[02 - Создание сервера]] и [[03 - Безопасность]].
2. Создай заметку сервера по шаблону [[Шаблоны/Паспорт сервера]].
3. Для каждого сервиса фиксируй назначение, зависимости, порты, хранилища и владельца.
4. Перед изменениями используй [[Шаблоны/План изменений]].
5. Обслуживание фиксируй по [[10 - Обслуживание]] и шаблону отчёта.

## Область применения

Базовая платформа: Ubuntu Server LTS / Debian, systemd, SSH, firewall, Docker Compose, Nginx или Caddy, PostgreSQL. Конкретные решения выбираются под задачу и угрозы.
